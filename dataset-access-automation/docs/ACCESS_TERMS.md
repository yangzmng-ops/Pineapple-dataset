# Pineapple Dataset Access Terms

Version: 2026-10-11-v1

These terms apply to new applications for access to the Pineapple Dataset.

## Access and use

Complete applications for academic research that is noncommercial and does not involve redistribution qualify for automatic reader access. Please provide accurate application information. The verified Google Account email address collected with your application is used to grant access to that account and send access-related notifications.

Commercial use or redistribution of the dataset or any part of it requires a separate application and approval. If your intended use changes to either of these, apply separately before proceeding.

Existing approvals remain unchanged. Previously approved readers do not need to agree to these terms retroactively.

## Citation

Please cite the accompanying paper when using the dataset in your research:

Yang, Ziming; Shan, Zhe; Hao, Xiaying; Lin, Cong; and Xue, Zhong. OALDNet: An orientation-aware lightweight detection network for precision pineapple harvesting. Applied Soft Computing, 200, 115442, 2026. https://doi.org/10.1016/j.asoc.2026.115442
